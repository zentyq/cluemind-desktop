Zero-Mouse Interview Shortcuts

Ctrl+Shift+S — Start or Stop live session

Ctrl+Shift+Space (or Ctrl+Enter) — Ask AI now

Ctrl+Shift+X (or Ctrl+Shift+D) — Capture & solve screen

Ctrl+Shift+Up / Down — Scroll AI answer / transcript

Ctrl+Shift+PageUp / PageDown — Fast scroll

Ctrl+Shift+E — Show / Hide full coding solution

Ctrl+Shift+Y — Copy latest code / answer

Ctrl+Shift+T — Switch AI / Transcript tab

Ctrl+Shift+M — Cycle mode (Meeting / Interview / Screen / Mock)

Ctrl+Shift+K — Clear chat & transcript

Ctrl+Alt+Arrow Keys — Move overlay window on screen

Ctrl+Shift+A / H — Show or hide overlay

Ctrl+Shift+Z — Minimize / expand pill

Ctrl+Shift+[ / ] — Decrease / increase opacity

Ctrl+Shift+C — Toggle Stealth No-Mouse (Click-Through)

Ctrl+Shift+, — Open / close Settings
